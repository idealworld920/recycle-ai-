## 출시 전 확인 (PC)

1. `git pull origin main` (리뿅이 에셋 전부 포함, 배경 투명화·정지 프레임 완료)
2. `flutter pub get` → `flutter analyze` → `flutter test`
3. `flutter build appbundle --release --dart-define-from-file=dart_defines.json`
4. Firebase: `firebase deploy --only functions,firestore:rules` (가족 공유 콜러블 + 웹훅 + **deleteUserData** + 규칙). +17 부터 데이터 삭제가 이 함수를 쓴다. Remote Config 에 `splash_message` 키(JSON, 비워두면 평소 스플래시).
5. RevenueCat: `resai_premium_monthly/yearly` → Entitlement `premium` → Offering `default` 의 Current. 웹훅 URL·시크릿 등록.
6. Play Console: 내부 테스트에 14 올리고 라이선스 테스터로 체험 시작·복원 확인 → 프로덕션 승격.

## Google 로그인 콘솔 체크리스트 (연결 무반응·설정 오류가 뜰 때)

1. **SHA 지문 3종이 Firebase 에 전부 있는지** — Firebase 콘솔 → 프로젝트 설정 → 내 앱(Android `com.idealworld.recycle_ai`) → SHA 인증서 지문:
   - 업로드 키 SHA-1·SHA-256: PC 에서 `keytool -list -v -keystore <업로드.jks> -alias <alias>`
   - **Play 앱 서명 키** SHA-1·SHA-256: Play Console → 테스트 및 출시 → 설정 → 앱 서명 → "앱 서명 키 인증서". 스토어 설치본은 이 키로 서명되므로 이게 빠지면 **계정 선택창은 뜨고 선택 후 무반응(코드 10 DEVELOPER_ERROR)** 이 된다.
   - 디버그 키(선택): `%USERPROFILE%\.android\debug.keystore` (`android`, alias `androiddebugkey`)
2. 지문을 추가했으면 **google-services.json 을 다시 받아** `android/app/` 에 교체하고 다시 빌드. 파일 안 `oauth_client` 에 `client_type: 3`(웹 클라이언트)이 있어야 idToken 이 나온다.
3. Firebase 콘솔 → Authentication → Sign-in method → **Google 사용 설정** + 지원 이메일.
4. Google Cloud 콘솔(`recycle-ai-de1e1`) → API 및 서비스 → **OAuth 동의 화면**: 게시 상태 "프로덕션"(테스트면 테스트 사용자 100명 제한·7일 만료). 앱 이름·지원 이메일·개발자 연락처 채움.
5. Google Cloud → 사용자 인증 정보: Android 유형 OAuth 클라이언트가 **패키지명 + 각 SHA-1 마다** 하나씩 있는지 (Firebase 가 자동 생성; 없으면 2번을 다시).
6. 기기에서 확인: `adb logcat | findstr "[auth]"` 로 `link 시도 → Google 토큰 받음 → link 성공` 순서가 찍히는지. `platform/10` 이면 SHA, `firebase/invalid-credential` 이면 웹 클라이언트(2번), `operation-not-allowed` 면 3번.
