## 간단한 설명 (80자 이내)
```
사진 한 장이면 끝. AI가 분리배출 방법, 수거일 알림, 헷갈리는 품목 팁까지 알려줘요.
```

## 자세한 설명 (4000자 이내)
```
"이거 어디에 버리지?" 더 이상 검색하지 마세요.
ReSAI(리사이)는 사진 한 장으로 분리배출 방법을 알려주는 AI 분리수거 앱이에요.

📷 찍으면 바로 알려줘요
쓰레기를 찍거나 갤러리에서 고르면 AI가 품목을 알아보고 어디에, 어떻게 버리는지 단계별로 알려줘요.
라벨을 떼야 하는지, 씻어야 하는지, 뚜껑은 어떻게 하는지까지.

🗓 수거일을 잊지 않게
우리 동네 재활용·일반·음식물 수거 요일을 등록하면 전날 저녁에 알려드려요.
홈 화면 위젯으로 D-day를 바로 볼 수 있고, "버렸어요" 체크로 주간 루틴이 쌓여요.

💡 헷갈리는 품목 55가지
컵라면 용기, 아이스팩, 깨진 유리, 폐건전지, 폐의약품…
환경부 분리배출 기준으로 정리한 팁을 검색해서 바로 확인하세요.

📍 버리는 곳까지
대형폐기물 신고 페이지, 폐의약품 수거함, 아이스팩·폐건전지 수거처 안내.
지역을 고르면 우리 동네 정보로 보여줘요.

📊 쌓이는 기록
분류한 내역이 기록으로 남고, 월간 요약과 수거일 연속 체크로 꾸준함이 보여요.
내가 분류해 본 품목은 도감으로 모아져요.

🔒 로그인 없이 바로 시작
회원가입 없이 바로 쓸 수 있어요. 기록을 다른 기기에서도 보고 싶을 때만 Google 계정을 연결하세요.
사진은 분류에만 쓰고 서버에 저장하지 않아요.

무료로 매일 사진 분류 5회, AI 질문 3회를 쓸 수 있어요.

• 분리배출 기준은 환경부 가이드라인을 따르며, 지자체별로 다를 수 있어요. 앱의 안내는 참고용이며 최종 기준은 거주 지역 안내를 확인해 주세요.
• 문의: idealworld13@gmail.com
```
