# 탄소 계수 조사 기록 (growth-2, 2026-11-12)

원칙: 환경부·한국환경공단·산림청·지자체 **공식 페이지에서 직접 확인한 수치**만 `assets/data/carbon_factors.json` 에 넣는다.
확인하지 못한 품목은 비워 두고, 리포트의 ⑥ 탄소 절감 섹션은 자동으로 숨긴다. (없음이 틀림보다 낫다)

## 채택 (carbon_factors.json)

| 항목 | 값 | 출처 | 확인 |
|---|---|---|---|
| 소나무 환산 | 6.6 kgCO2/그루/년 (30년생 소나무) | 서울특별시 기후환경본부 보도자료 「서울시, 온실가스 목표관리제로 여의도면적 110배 숲 조성효과」(2013), 국립산림과학원 인용 — https://news.seoul.go.kr/env/archives/31374 | 원문 인용: "30년생 소나무 1그루가 연간 흡수하는 이산화탄소(CO2) 흡수량 : 6.6kg … (국립산림과학원)" |

- 국립산림과학원 원 자료(「주요 산림수종의 표준 탄소흡수량」)는 forest.go.kr 접속 불가로 직접 열람하지 못했고, 서울시 공식 보도자료의 인용을 근거로 채택.
- 품목별 계수(`factors`)가 비어 있어 현재 앱에서는 소나무 환산도 표시되지 않는다. 품목 계수가 채워지면 자동으로 함께 표시된다.

## 다음에 채우려면

1. 환경부 「탄소중립 생활 실천 안내서」(2021/2024) 본문에서 **품목 1개당** 또는 **kg당 + 품목 평균 무게**가 함께 제시된 표를 찾는다.
2. 한국환경공단 「환경성적표지」·「재활용 환경성 평가」 공식 문서에서 재질별 재활용 시 온실가스 감축 계수(kgCO2e/kg)를 확인한다.
3. `carbon_factors.json` 의 `factors` 에 `tipId` 또는 `category:<key>` 키로 넣는다. kg 단위 계수는 `typicalWeightKg` 와 `weightSource` 가 함께 있어야 `tool/validate_data.dart` 를 통과한다.
